# vimage

A lightweight and fast image viewer for Windows.

## Features

- Fast startup
- Lightweight
- Automatic image fitting
- Mouse wheel zoom
- Pan with the mouse wheel
- Transparency checkerboard
- Window resizing support

## Supported Formats

- PNG
- JPEG (.jpg, .jpeg)

## Building

```bash
cmake -B build
cmake --build build
```

## Dependencies

- raylib
- stb_image
